# Narrative Twist Deluxe

Interactive mini-game: Attack, Mock, Empathize & see if you’re a Viral Warrior 😎🔥

## Instructions
1. Open `index.html` in your browser.
2. Click Attack, Mock, or Empathize as fast as you can.
3. Watch your Chaos, Clout, and Humanity stats.
4. Reach the end to see if you’re a Viral Warrior!

Have fun trolling your friends in the Hate Club 😏
